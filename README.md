# CozyMoney

주식·세금·부동산·재무회계 등 금융과 경제 정보를 초보자도 이해하기 쉽게 정리하는 정보 콘텐츠 사이트입니다.

[CozyMoney](https://cozymoney.kr)

---

## 소개

CozyMoney는 복잡한 금융·세무·회계 정보를 쉽고 이해하기 편한 형태로 제공하는 개인 정보 콘텐츠 사이트입니다.

주요 콘텐츠 분야는 다음과 같습니다.

- **주식** — 주식 기본 개념, ETF, 기업 분석 등
- **세금** — 소득세, 부가가치세, 연말정산, 세액공제, 각종 세금 제도 등
- **재무회계** — 재무제표, 회계 개념, 회계 처리, 재무회계 기초 등

---

## 주요 특징

### Markdown 기반 콘텐츠

게시글 원고를 Markdown으로 작성하고 빌드 과정에서 웹사이트에서 사용할 수 있는 형태로 변환합니다.

### SPA 방식의 웹사이트

Vanilla JavaScript를 이용하여 페이지 전체를 새로고침하지 않고 카테고리와 게시글 콘텐츠를 전환합니다.

### SEO 최적화

게시글별 정적 HTML을 생성하여 검색엔진이 게시글 내용을 직접 확인할 수 있도록 구성합니다.

사이트맵과 게시글 데이터를 자동으로 생성하여 검색엔진 색인에 필요한 구조를 제공합니다.

---

## 기술 스택

- **Bun** — JavaScript 런타임 및 프로젝트 실행
- **Vanilla JavaScript** — 웹사이트 및 자동화 로직
- **UnoCSS** — 유틸리티 기반 CSS
- **Markdown** — 게시글 원고 관리
- **SPA** — 클라이언트 사이드 페이지 전환

```text

│   └── data/
│       └── posts/                  # Markdown 게시글
│
│
│
├── pages/

│   ├── data/
```

## 개발 환경

- Bun

```bash

```

## 개발 서버

```bash
bun run dev
```

개발 환경에서 웹사이트를 실행할 수 있습니다.

---

## 사이트 빌드

```bash
bun run build
```

빌드 과정에서 Markdown 게시글과 게시글 데이터를 기반으로 웹사이트에 필요한 파일을 생성합니다.

---

## 콘텐츠 관리

게시글 원고는 Markdown 형식으로 관리합니다.

```text
src/data/posts/
```

게시글을 추가하거나 수정한 후 사이트 빌드를 실행하면 웹사이트에 반영됩니다.

---

## 검색엔진 최적화

CozyMoney는 검색엔진 최적화를 위해 다음 요소를 관리합니다.

- 게시글별 정적 HTML
- `sitemap.xml`
- `robots.txt`
- 게시글별 메타 정보
- 카테고리 구조
- 검색엔진이 접근할 수 있는 콘텐츠 구조

## 라이선스

이 저장소의 코드는 개인 프로젝트 및 학습·참고 목적으로 공개되어 있습니다.

게시된 글 콘텐츠의 무단 복제 및 배포를 금지합니다.

## 이미지 제공 방식

자동 포스팅의 이미지는 생성형 AI를 사용하지 않고 Pexels API에서 검색한다.

- 게시글 1개당 최대 2개 이미지
- 최소 1개 이미지를 확보해야 게시 가능
- Pexels 검색 결과에서 게시글 제목·키워드와 관련성이 높은 이미지를 우선 선택
- 가로형(landscape) 이미지 사용
- 이미지 파일을 프로젝트에 저장하지 않음
- Pexels CDN URL을 Markdown에 직접 삽입
- 사진가와 Pexels 출처 링크를 게시글에 표시
- 로컬 `public/images/posts` 이미지 지원하지 않음
- Cloudflare Workers AI 및 AI Horde 이미지 생성 기능을 사용하지 않음

Pexels API 키는 `.env`의 `PEXELS_API_KEY`에 설정한다.
